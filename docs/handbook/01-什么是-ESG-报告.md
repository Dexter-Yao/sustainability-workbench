# 第 1 章 什么是 ESG 报告

### 1.1 为什么需要 ESG 报告

大多数企业第一次接触「ESG 报告」，不是因为想做，而是因为有人来要：客户的年度供应商审核清单上多了一行「请提供贵司最近一期的 ESG 报告」，或者投标评分细则里有一栏给可持续发展表现打分。

监管口径叫可持续发展报告，市场上也叫 ESG 报告或社会责任报告，指的是同一类文件。最终交付的文档标题通常是**《可持续发展报告》**。

### 1.2 ESG 三个字母分别指什么

| 字母 | 英文 | 中文 | 关注什么 |
|------------|---------------------|------------|--------------------------------------------------------------------------------------------|
| E | Environmental | 环境 | 能源和水的消耗、排放、废弃物、对气候变化的应对 |
| S | Social | 社会 | 员工、客户、供应商、社区：用工与培训、职业健康安全、产品质量、数据保护 |
| G | Governance | 治理 | 谁来决策、按什么规则决策、防商业贿赂与不正当竞争、风险管理 |

这三类关注面正式的叫法是**维度**，也可以叫**门类**，不叫「三大章」。E、S、G 是给议题分类用的标签，不是章节的划分方式。

### 1.3 一份 ESG 报告长什么样

| 章 / 节 | 内容 |
|-----------------------------|-------------------------------------------------------------------------------------------------------------|
| **关于本报告** | 披露范围（只有公司本部，还是母公司加全部并表子公司——这决定后面所有数字的含义）、报告时间范围、编制依据、披露原则、联系方式、外部鉴证情况（如有）、审批情况（如有） |
| **关于公司** | 发展历程、主营业务、产品和服务、市场覆盖、战略愿景 |
| **公司治理** | 股东会、董事会、管理层的构成与权责，基本运行机制，治理层面的合规与透明度 |
| **可持续发展治理** | 分三节：**可持续发展治理架构**（哪些机构、部门或岗位参与管理，各自负责什么）、**利益相关方沟通**（通常做成一张表）、**议题重要性评估**（含双重重要性矩阵图与议题评估结果表，） |
| **议题章节** | 按五个报告模块组织，见下表 |
| **附录** | **ESG 关键绩效表**（议题类别、指标、单位、报告年度数值、口径备注）、**索引表**（准则条款与本报告章节的对照）、外部鉴证声明（如有）、读者反馈（如填了联系方式） |

议题章节不是环境、社会、治理三大块，而是按五个模块组织：

| 模块 | 包含的议题章节 |
|-----------------------|-----------------------------------------------------------------------------------------------------------|
| 环境可持续 | 应对气候变化、环境合规管理、污染物排放管理、废弃物管理、促进循环经济、能源管理、水资源管理、生态系统与生物多样性保护 |
| 人与社区 | 人力资本发展、职业健康与安全、乡村振兴与社会贡献 |
| 创新与产品责任 | 创新驱动、产品质量与安全、客户服务质量管理 |
| 可持续价值链 | 可持续供应链管理、平等对待中小企业、科技伦理、数据安全与客户隐私保护 |
| 负责任治理 | 反商业贿赂与反贪污、反不正当竞争、风险管理、尽职调查 |

「人与社区」「创新与产品责任」「可持续价值链」三个模块里的议题在维度上全都属于社会。**维度是给议题贴的分类标签，模块是报告的编排方式。** 模块在最终报告里的标题不会直接叫「环境可持续」，而是结合实际包含的议题另起章节名。

每个议题章节内部结构统一，分三节：**治理**（归谁管、有什么制度和流程）、**战略**（基本原则与关注方向）、**影响、风险与机遇管理**（带来什么风险和机遇，对外部环境和社会有什么影响，怎么应对）。
