# 矩阵图中文字体

`export/matrix_chart.py` 渲染双重重要性矩阵图时，按以下顺序选用中文字体：

1. 本目录（`backend/data/fonts/`）下的 `.ttf` / `.otf` 文件（优先注册）。
2. 系统已安装的常见中文字体（思源黑体、苹方、宋体、微软雅黑、文泉驿微米黑等）。

开发机通常已具备系统中文字体。**生产 / 部署环境若无系统中文字体，请将一个开源中文字体放入本目录**（建议思源黑体 Source Han Sans SC，SIL OFL 许可、可商用），以杜绝图中中文显示为方框。

字体二进制文件是否纳入版本库由部署策略决定；本目录与 README 仅保证渲染逻辑有确定的字体加载位置。
